# 出版物与影视轻量资料

本集合保留经人工核查的 7 个出版物根、2 个番剧根及 2 个电影根。`references.json` 保存原参考身份和格式事实；`cases.json` 保存缩减输入对应的独立预期。素材、响应和验证调用方都在环境平台之外。

6 份 EPUB 是带 CRC、容器、包元数据、目录、书脊与合成单章的有效 EPUB；通用文件名 `publication.epub` 使标题验证必须经过解析。原作者、角色、出版日期、出版社及系列字段保留，包路径统一为 `OPS/book.opf`，原参考中的定位符用于追溯原文件。封面改用小型有效 PNG，前四份使用元数据封面声明，后两份使用清单封面声明，每份只有一个封面候选。正文、原始书籍及完整封面未复制。

PDF 根包含原三个相对路径。每份均为有效、可渲染的一页 PDF，保留文档作者“水橋 松梨”，页数预期明确变为 1。页面只含合成矩形，封面由实际第一页渲染产生；不把文档作者当作品作者，不凭文件名制造 ISBN。两份《幼女战记》沿公开来源补充入口使用原核查 ISBN 查询 NBINet，并分别检查格式与来源事实。

番剧包含《终将成为你》第一季第 1、13 集，以及《葬送的芙莉莲》第一季第 1、28 集和第二季第 1 集。官方主体及剧集编号、季内顺序和跨季连续顺序来自既有参考；第二季第 1 集的连续顺序为 29。标题、简介等其余协议字段是缩减响应中的固定展示文本，不代表重新抓取的实时资料。Bangumi 搜索响应包含两个参考主体，产品按实际请求的片名与年份筛选；清单不支持同 URL 按正文分派，因此只有一个搜索条目。

严格命名电影《恐怖直播 (2013)》验证自动识别。非规范收藏包《怒火救援》使用公开定向来源输入指定 TMDB 9509；包内两条流及结构文件应共同归属于一个资产，不生成蓝光版或媒体流资产。MP4/M2TS 复用已有 77 字节结构样本，BDMV/MPLS 只保留识别所需小型结构标记，均不提供完整播放证明。

TMDB 与 OMDb 的电影、IMDb 编号及年份来自原参考；来源响应中的简介、导演、奖项、票房和评分均是明确标记或固定的合成协议值，用于核对两个来源的独立贡献，不能用作真实影片评价。OMDb 发布日期采用其实际传输格式 `DD Mon YYYY`。有效 PNG/JPEG 为自有合成图片，分别按来源声明媒体类型提供，验证器从当前产品数据根经真实 HTTP 读取。

全部来源请求沿已接受的受控外部 I/O 装配，未知请求失败，合成 OAuth 与 API 令牌不是个人凭据。验证通过公开来源设置、资产库接入、刷新、来源补充、CLI 扫描与内容读取执行；Web 与 CLI 顺序持有同一数据根，不注入数据库或资产。封面需求通过普通 CLI 扫描显式请求，格式和来源事实分别核对。失败环境保留，成功环境在保存证据并停止后删除；输入摘要必须保持不变。

在仓库根目录运行，环境名、证据文件和端口须由调用者独占：

```bash
node scripts/verify-publication-screen-corpus.ts publication-screen-demo /tmp/publication-screen-demo.json 54013
node scripts/verify-publication-screen-corpus.ts publication-only /tmp/publication-only.json 54014 epub-1 pdf-three
node scripts/verify-publication-screen-corpus.ts screen-only /tmp/screen-only.json 54015 anime-frieren film-directed
```

实际结果及失败范围由每次证据文件给出。该集合证明普通目录接入、实际格式解析、身份与关系、来源贡献及封面可读性，不代表完整阅读、播放、性能或真实网络验收。
