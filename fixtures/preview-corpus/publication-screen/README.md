# 出版物与影视参考资料

本资料集覆盖原定 11 个根：6 份 EPUB、一个含 3 册 PDF 的逻辑根、2 个番剧根和 2 个电影根。`references.json` 记录原参考身份及逐项核查的格式事实；`cases.json` 是本验收独立的缩减预期。病例按根统计，不按文件或图片数量统计。

六份 EPUB 保留真实 OPF 标题、作者、语言、出版社、日期、系列字段，以及原文件中嵌入的 JPEG 封面；《妹妹人生》上下册的原始 OPF 含简介，其余册没有简介时保持缺失。它们保留有效 EPUB 容器和封面资源，不包含完整书籍正文，也不证明阅读器排版行为。两个有有效 ISBN 的《幼女战记》册另通过已验证的 NBINet 精确查询核对正式记录。

PDF 根保留原目录下的三条册级相对路径。每个缩减 PDF 只含真实参考 PDF 的首页，保留原文档作者并能被正式 PDF 来源解析，页数因此为 1。三张独立封面参考根据 `references.json` 的摘要与原相对路径，从 `.scratch/acceptance-corpus/assets/appdata/booklore/books/轻小说/入间人间/やがて君になる 佐伯沙弥香について/` 下对应的真实 PDF 首页，用 Poppler 22.12.0 的 `pdftoppm -f 1 -l 1 -singlefile -png -r 72 <原始PDF> <输出前缀>` 直接渲染保存；不是产品 PDF 解析器或托管接口的输出。正式接口返回 PNG 后，验收检查 PNG 格式与 596×842 尺寸，并解码比较 RGB 内容；同册参考的通道绝对差均值须不超过 12，两张错册参考都须高于该阈值。当前三组正确配对差值为 3.72、6.07、5.14，错册配对的最低差值为 53.65。这里核对首页图像，不把它说成完整出版物正文。文档作者不作为作品作者，也不添加来源中不存在的题名或 ISBN。

番剧缩减保留《终将成为你》第一季第 1、13 集，以及《葬送的芙莉莲》第一季第 1、28 集和第二季第 1 集。作品标题、简介、封面和剧集映射来自 Bangumi 官方记录；后两季精确关联，并分别核对季内序号与全系列顺序。各视频是从已确认本地参考缩短重编码的有效 H.264 样本，用于验证材料持久化和 HTTP 字节范围读取，不代表完整剧集播放。

《恐怖直播》保留真实 TMDB 影片记录、导演、简介、海报和有效短 MP4 样本，并通过 OMDb 记录核对其奖项贡献。蓝光目录样本以 TMDB 9509 定向识别《Man on Fire》；真实详情提供英语片名、简介、上映日、片长、类型、导演和海报。该样本没有独立核实的 OMDb 记录，受控请求明确返回 HTTP 503；正式流程应留下 TMDB 成功与 OMDb 部分失败，不能显示为完整来源成功。它保留原 BDMV 索引和播放列表及两条有效的短 M2TS 样本，验证格式结构和媒体字节范围读取；不验证完整蓝光包播放或 18 条流的布局。

所有封面都经正式托管产物流程读取。EPUB、TMDB 与 Bangumi 的 JPEG 仍按独立来源图片逐字节核对；PDF PNG 按上述独立 `pdftoppm` 图像参考核对，不要求不同渲染器输出相同编码字节。所有外部来源请求都通过既有受控 I/O 清单回放；未知请求失败，不会联网回退。清单中的合成 OAuth/API 凭据只用于产品连接设置，不是个人凭据，也不需要私人材料。原始参考仅用于核实及生成缩减内容，验收运行不依赖私人文件或参考目录。

从仓库根运行，环境名、证据路径和端口须独占：

```bash
pnpm verify:publication-screen publication-screen-demo /tmp/publication-screen-demo.json 54013
pnpm verify:publication-screen publication-only /tmp/publication-only.json 54014 epub-1 pdf-three
pnpm verify:publication-screen screen-only /tmp/screen-only.json 54015 anime-frieren film-directed
```

正式验收经公开目录接入、观察、格式解析、来源采集与解释、定向识别、CLI 扫描和 HTTP 产品读取执行。成功环境在保存证据并停止后删除；失败环境保留诊断。它覆盖标题、实际存在的简介、来源身份、目录关系、封面字节和短媒体范围读取；不覆盖完整阅读、完整影片或番剧播放、画质、性能及真实来源联网。
