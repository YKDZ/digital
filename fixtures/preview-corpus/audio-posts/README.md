# 音声、帖子与未识别轻量资料

本集合包含 8 个 DLsite 音声根、5 个 FANBOX 帖子根，以及 3 个音乐发行物、1 个目录画集和 1 个目录漫画参考。输入、受控响应和独立预期随仓库取得；环境实现只收到普通目录及来源配置。

`cases.json` 提供稳定资料 ID、普通目录、逐根预期及原文件到缩减文件的映射。`references.json` 摘录既有人工审阅记录中的身份、标题、发布日期、参与者、系列和附件信息，并记录 2026-10-16 从官方 DLsite 产品页、产品 JSON 和 FANBOX 帖子页观察到的页面地址、简介、封面地址及图片摘要。预期依据这些外部参考和既有审阅记录预先保存，不从运行结果生成；这些记录用于选材和独立核对，不授予其他媒体管理器来源权威。

本集合沿用已经交付的普通来源请求和 FANBOX 会话装配。`manifest.json` 精确声明允许的请求与封闭端点，未知请求明确失败。`connections/synthetic-customudon.json` 是既有合成浏览器上下文，没有真实登录能力，必须经正式产品设置导入。受控成功不代表当前真实来源或付费访问成功。

缩减方式如下：

- 音声保留原根身份及选中的目录层级、普通版本、差分或附加材料。音频字节复用既有合法小型 PCM WAV；原 MP3 和 FLAC 文件在映射中保留参考名称，输入转换为明确标注的 PCM 缩减文件。它们不证明原编码、音质或完整播放。
- 帖子保留创作者、日期目录、适用的普通与特别篇文件。父目录使用正式 `creatorId=customudon`。MP4 复用既有最小结构盒序列，用于观察与材料关系，不是完整可播放视频。附件名称、大小和正文来自既有审阅记录；响应中的附件 URL 和 ID 是协议代表值，不声称下载了原附件。
- 8 个音声封面和 4 个帖子专属封面均为从官方页面声明的 CDN 地址取得的 JPEG 实际字节。每根独立参考记录来源地址、媒体类型、长度与 SHA-256；验收从当前产品数据根读取托管图片并逐字节核对。新年帖子页面使用创作者通用 `og:image`，没有帖子专属封面，因此保持 absent，不把创作者图片冒充帖子封面。
- 音乐及目录图文资料只覆盖安全观察与明确未识别。小型合成媒体和保留的最少目录、CUE/LOG 参考用于表达该范围；本集合不声称完整曲目、原 FLAC 解码、332 页读取或媒体性能。

来源 JSON 保留需要核对的参考字段，HTTP 信封、成功会话状态、FANBOX 附件地址与 ID、以及省略的非必要字段采用既有解析协议的代表值。FANBOX 本集合使用不含真实登录能力的合成浏览器上下文和封闭受控响应；不要求私人目录、个人凭据或来源网络，也不由历史会话状态推断现实中的当前权限。

参与者预期遵循既有 DLsite 列表字段契约。RJ01497788 官方页面把 `朱里 / shuri` 作为一个完整参与者标签展示，预期也按单项精确核对。其余参与者逐个核对完整标签，不用子串命中替代。

通过现有公开环境生命周期与普通目录客户端执行：

```sh
pnpm verify:audio-posts <独立环境名> <证据文件> <空闲端口>
```

末尾可指定 `cases.json` 中的资料 ID，选择同一集合的子集。验证通过正式资产库、扫描、资产刷新、内容读取和产物 HTTP 入口检查结果，分别记录安全观察、识别和未识别；停止后重开检查可读状态，比较素材前后内容摘要。失败时保存证据并停止自有服务，保留可排查现场；成功后才回收新建环境。资料脚本位于根目录既有类型、格式和 lint 检查范围内。
